# 幂等关键链路测试补充

## 概述

本次开发补充了幂等关键链路的单元测试和集成测试，确保系统在重复提交、重复回调、外盒重发等场景下的正确行为。

## 完成内容

### 1. 重复提交测试

**文件**: `task-gateway/src/test/java/com/ast/platform/gateway/TaskIdempotentSubmissionTest.java`

测试场景：
- 相同requestId重复提交应返回幂等结果
- 相同bizKey重复提交应返回幂等结果
- 不同requestId和bizKey应创建新任务

### 2. 外盒重发测试

**文件**: `task-gateway/src/test/java/com/ast/platform/gateway/OutboxRepublishTest.java`

测试场景：
- NEW状态外盒可被重发
- SENT状态外盒不应被重发
- FAILED状态外盒重发后重试计数正确递增

修复问题：
- 表名从 `task_publish_outbox` 修正为 `gateway_publish_outbox`
- 字段名从 `id` 修正为 `outbox_id`
- 补充缺失字段：`tenant_id`, `task_type`, `topic`, `payload`

### 3. 重复回调测试

**文件**: `task-scheduler/src/test/java/com/ast/platform/scheduler/CallbackIdempotentTest.java`

测试场景：
- 重复成功回调应幂等处理
- 无效dispatchToken应被拒绝
- 终态不可被覆盖（SUCCESS后不能改为FAILED）
- 重复重试回调应正确处理

### 4. Worker选点算法测试

**文件**: `task-scheduler/src/test/java/com/ast/platform/scheduler/infrastructure/selector/LeastLoadedWorkerSelectorTest.java`

测试场景：
- 选择负载最低的Worker
- 从已排序列表选择第一个候选
- 空Worker列表返回空结果

**文件**: `task-scheduler/src/test/java/com/ast/platform/scheduler/infrastructure/selector/RoundRobinWorkerSelectorTest.java`

测试场景：
- 轮询选择Worker
- 循环回到第一个Worker
- 空Worker列表返回空结果

### 5. Redis队列原子操作测试

**文件**: `task-scheduler/src/test/java/com/ast/platform/scheduler/infrastructure/repository/RedisDispatchQueueRepositoryTest.java`

测试场景：
- 任务入队
- 任务出队
- 超时任务回收
- 任务提交/回滚
- 重试队列操作

## 关键修复

1. **SQL表结构对齐**：测试SQL与实际schema保持一致
2. **方法签名修复**：`acceptSubmittedTask` 添加 `priority` 参数
3. **Record访问器修复**：`isIdempotent()` 改为 `idempotent()`
4. **字段名修复**：`createdAt` 改为 `enqueuedAt`，`next_retry_at` 改为 `next_retry_time`
5. **构造函数参数修复**：`ReadyTaskEnvelope` 添加 `priority` 参数
6. **Worker选点器构造函数修复**：`RoundRobinWorkerSelector` 需要 `StringRedisTemplate` 参数

## 符合AGENTS.md约束

- 所有状态推进幂等
- 终态不可覆盖
- 回调改写状态前校验dispatchToken
- 允许重复，不允许静默丢失
