# 真实 Pump 搬运实现 (RocketMQ 5 gRPC)

## 本次进展

- 为 `task-scheduler` 引入 `rocketmq-client-java` 5.0.6 依赖
- 新增 `ast.scheduler.rocketmq.*` 配置类与默认参数
- 实现基于 RocketMQ 5 `PushConsumer` 的 `RocketMqPumpConsumer`
- 实现了消息体 JSON 解析，并将其入队到 Redis 逻辑调度队列
