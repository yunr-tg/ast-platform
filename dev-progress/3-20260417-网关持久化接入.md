# 网关持久化接入

## 本次进展

- 为 `task-gateway` 接入 `spring-boot-starter-jdbc`
- 补充 H2/MySQL 兼容的数据源配置，占位支持后续切换真实 MySQL
- 新增 `gateway_task` 与 `gateway_publish_outbox` 表结构初始化脚本
- 新增 JDBC 版任务仓储与入队外盒仓储实现
- 将内存版仓储调整为可选回退实现，默认启用 JDBC 存储
- 调整网关提交编排，先提交任务事实与外盒，再执行消息发送与状态回写
- 保留日志型消息发布器，作为后续 RocketMQ Producer 的替换点
- 完成整仓 `mvn test` 验证

## 当前状态

- `task-gateway` 已具备基于数据库的任务事实和入队外盒落账能力
- 当前默认使用 H2 作为本地运行与测试存储，生产仍需切换真实 MySQL
- MQ 发送仍为模拟实现，尚未接入 RocketMQ

## 下一步建议

- 接入 MySQL DDL 管理和持久化字段约束
- 接入 RocketMQ Producer，替换日志型消息发布器
- 为外盒记录补齐失败原因、下次重试时间、发送审计字段
- 为任务状态更新补齐版本条件更新与幂等防重逻辑
