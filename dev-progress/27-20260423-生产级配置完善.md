# 生产级配置完善

## 概述

本次开发完善了AST Platform的生产级配置，包括数据库连接池、Redis连接池、RocketMQ、线程池、超时重试策略、监控健康检查等核心配置。

## 配置文件清单

### Nacos配置中心文件

| 文件名 | 用途 |
|--------|------|
| `ast-platform-common.yaml` | 公共配置（Jackson、日志、熔断器） |
| `ast-platform-datasource.yaml` | 数据源与HikariCP连接池配置 |
| `ast-platform-redis.yaml` | Redis连接池与调度队列配置 |
| `ast-platform-rocketmq.yaml` | RocketMQ生产者/消费者配置 |
| `ast-platform-threadpool.yaml` | 各子系统线程池配置 |
| `ast-platform-retry.yaml` | 超时与重试策略配置 |
| `ast-platform-observability.yaml` | 监控、健康检查、日志配置 |
| `task-gateway.yaml` | Gateway专属配置 |
| `task-scheduler.yaml` | Scheduler专属配置 |
| `task-gateway-dev.yaml` | Gateway开发环境配置 |
| `task-scheduler-dev.yaml` | Scheduler开发环境配置 |
| `task-gateway-prod.yaml` | Gateway生产环境配置 |
| `task-scheduler-prod.yaml` | Scheduler生产环境配置 |

## 配置详情

### 1. 数据库连接池（HikariCP）

```yaml
hikari:
  pool-name: AST-HikariPool
  maximum-pool-size: ${HIKARI_MAX_POOL_SIZE:20}
  minimum-idle: ${HIKARI_MIN_IDLE:5}
  idle-timeout: ${HIKARI_IDLE_TIMEOUT:300000}
  connection-timeout: ${HIKARI_CONNECTION_TIMEOUT:10000}
  max-lifetime: ${HIKARI_MAX_LIFETIME:1200000}
  connection-test-query: SELECT 1
  leak-detection-threshold: ${HIKARI_LEAK_DETECTION:60000}
  validation-timeout: ${HIKARI_VALIDATION_TIMEOUT:3000}
```

### 2. Redis连接池（Lettuce）

```yaml
lettuce:
  pool:
    max-active: ${REDIS_POOL_MAX_ACTIVE:16}
    max-idle: ${REDIS_POOL_MAX_IDLE:8}
    min-idle: ${REDIS_POOL_MIN_IDLE:4}
    max-wait: ${REDIS_POOL_MAX_WAIT:2000ms}
```

### 3. RocketMQ配置

```yaml
rocketmq:
  producer:
    send-message-timeout: ${ROCKETMQ_SEND_TIMEOUT:3000}
    retry-times-when-send-failed: ${ROCKETMQ_SEND_RETRY:3}
    max-message-size: ${ROCKETMQ_MAX_MESSAGE_SIZE:4194304}
    enable-message-trace: true
```

### 4. 线程池配置

```yaml
ast:
  thread-pool:
    dispatcher:
      core-size: ${DISPATCHER_POOL_CORE:2}
      max-size: ${DISPATCHER_POOL_MAX:8}
    pump:
      core-size: ${PUMP_POOL_CORE:4}
      max-size: ${PUMP_POOL_MAX:16}
    callback:
      core-size: ${CALLBACK_POOL_CORE:4}
      max-size: ${CALLBACK_POOL_MAX:16}
```

### 5. 重试策略

```yaml
ast:
  retry:
    strategy: ${RETRY_STRATEGY:EXPONENTIAL_BACKOFF}
    initial-delay-ms: ${RETRY_INITIAL_DELAY:1000}
    max-delay-ms: ${RETRY_MAX_DELAY:60000}
    multiplier: ${RETRY_MULTIPLIER:2.0}
    max-attempts: ${RETRY_MAX_ATTEMPTS:5}
    jitter-enabled: ${RETRY_JITTER:true}
```

### 6. 监控与健康检查

```yaml
management:
  endpoints:
    web:
      exposure:
        include: health,info,prometheus,metrics,env,loggers,caches
  health:
    db:
      enabled: true
    redis:
      enabled: true
  metrics:
    distribution:
      percentiles-histogram:
        http.server.requests: true
      slo:
        http.server.requests: 100ms,200ms,500ms,1s,2s
```

## 环境变量支持

所有关键配置均支持环境变量覆盖，便于Kubernetes部署：

- `MYSQL_HOST` / `MYSQL_PORT` / `MYSQL_DB` / `MYSQL_USERNAME` / `MYSQL_PASSWORD`
- `REDIS_HOST` / `REDIS_PORT` / `REDIS_PASSWORD`
- `ROCKETMQ_NAME_SERVER`
- `NACOS_SERVER_ADDR` / `NACOS_NAMESPACE`
- `SPRING_PROFILES_ACTIVE`

## 配置加载顺序

1. `ast-platform-common.yaml` - 公共基础配置
2. `ast-platform-datasource.yaml` - 数据源配置
3. `ast-platform-redis.yaml` - Redis配置
4. `ast-platform-rocketmq.yaml` - RocketMQ配置
5. `ast-platform-threadpool.yaml` - 线程池配置
6. `ast-platform-retry.yaml` - 重试策略配置
7. `ast-platform-observability.yaml` - 监控配置
8. `{application}.yaml` - 服务专属配置
9. `{application}-{profile}.yaml` - 环境特定配置

- 禁止硬编码地址、Topic、阈值、密钥
