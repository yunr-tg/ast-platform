# 开发进度记录 - 20260421

## 19. 主流调度算法全集实现

### 1. 架构扩展
- **领域层**: 在 `ast-platform-domain` 中定义了 `SchedulingStrategy` 枚举，支持：
    - `LEAST_LOADED`: 最闲优先（默认，考虑槽位、错误率、响应时间）。
    - `RANDOM`: 随机分配。
    - `ROUND_ROBIN`: 轮询（使用 Redis 计数器支持分布式一致性）。
    - `CONSISTENT_HASH`: 一致性哈希（目前基于 `taskId`）。
    - `WEIGHTED_RANDOM`: 加权随机。
- **数据层**: 
    - 升级 `scheduler_worker` 表，增加 `weight` 字段（默认 100）。
    - 更新 `WorkerRuntimeSnapshot` 和 `JdbcWorkerRuntimeRepository` 以持久化权重信息。
- **协议层**: `WorkerRegisterRequest` 增加 `weight` 字段，允许 Worker 自主上报权重。

### 2. 调度策略实现 (Infrastructure)
- 实现了 `WorkerSelector` 接口及其五种实现类。
- **RoundRobin**: 采用 `ats:scheduler:rr:index:{workerGroup}` Redis 键存储全局计数。
- **WeightedRandom**: 基于 Worker 权重的区间随机选择。
- **ConsistentHash**: 基于哈希取模的简易实现。

### 3. Dispatcher 重构
- `DispatcherApplicationService` 接入 `WorkerSelector` 委派机制。
- 支持通过 `ast.scheduler.strategy` 配置项动态切换调度策略。

### 4. 自动化验证
- 新增 `SchedulingStrategyIntegrationTest`。
- 验证了随机性的分布、轮询的周期性以及权重的显著性（50 次任务中，90% 权重 Worker 占比超过 60%）。
