# PRD - 异步任务调度平台

## 1. 产品目标
提供统一、可靠、可观测的异步任务调度平台，承接集团异步任务接入、调度、执行、回调与补偿。

## 2. 目标用户
- 业务系统接入方
- 平台运维人员
- 研发排障人员
- 架构与治理团队

## 3. 核心能力
### 3.1 任务接入
- 支持 HTTP/gRPC 提交任务
- 支持任务类型、租户、优先级、回调地址等参数
- 支持幂等提交

### 3.2 任务调度
- 统一缓冲与削峰
- 按 `tenantId + taskType` 维度调度
- 基于 Worker 资源状态进行智能路由

### 3.3 状态管理
- 支持任务状态查询
- 支持重试、死信、超时标记
- 支持人工终止与人工补偿

### 3.4 业务回调
- 任务终态后异步通知业务方
- 支持签名、重试、死信、人工补发

### 3.5 运维与排障
- 任务检索
- TraceID 串联
- 监控大盘
- 异常告警

## 4. MVP 范围
- Gateway
- Scheduler
- Worker SDK
- Callback Service
- Notify Dispatcher
- Compensator
- 基础监控与人工补偿

## 5. 非目标
- 工作流编排
- 多租户差异化资源治理
- 商业化运营功能
