# 数据字典

## 1. 核心字段
| 字段 | 含义 | 说明 |
| --- | --- | --- |
| taskId | 任务唯一标识 | 雪花算法生成 |
| tenantId | 租户标识 | 平台调度维度之一 |
| taskType | 任务类型 | 路由与处理能力标识 |
| status | 任务状态 | INIT/QUEUED/RUNNING 等 |
| dispatchToken | 派发令牌 | 防止晚到回调覆盖 |
| callbackUrl | 业务回调地址 | 任务终态通知地址 |
| callbackStatus | 业务回调状态 | NEW/SUCCESS/RETRY_WAIT/DEAD |
| workerId | Worker 实例标识 | 心跳与资源状态主键 |
| workerGroup | Worker 组 | 执行器能力分组 |
| availableSlots | 可用并发槽位 | 调度决策依据 |
| traceId | 跟踪标识 | 全链路日志追踪 |

## 2. 任务状态枚举
- INIT
- QUEUED
- DISPATCHED
- RUNNING
- SUCCESS
- FAILED
- RETRY_WAIT
- DEAD_LETTER
- CANCELLED

## 3. Worker 状态枚举
- UP
- DEGRADED
- DRAINING
- DOWN
- BLOCKED

## 4. 业务回调状态枚举
- NEW
- SENDING
- SUCCESS
- RETRY_WAIT
- DEAD
- CANCELLED
