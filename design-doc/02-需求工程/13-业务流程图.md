# 业务流程图

## 1. 主流程泳道说明
建议泳道角色：
- 业务系统
- Gateway
- Scheduler
- Worker
- Callback Service
- Notify Dispatcher
- 运营平台

## 2. 核心流程
1. 业务系统提交任务
2. Gateway 落库并入队
3. Scheduler 拉取任务并路由到 Worker
4. Worker 执行并回调平台
5. 平台更新终态并清理执行态
6. 若配置业务回调，则 Notify Dispatcher 通知业务系统
7. 若失败则进入重试、超时扫描或死信处理

## 3. 建议绘图标准
- 采用 BPMN 或泳道图
- 对异常分支单独标红
- 对“任务终态”和“通知终态”分开建模
