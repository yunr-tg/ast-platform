# 用例图与用户故事

## 1. 角色
- 业务系统
- 平台运维
- 平台研发
- Worker 节点

## 2. 核心用例
- 提交任务
- 查询任务状态
- 回调业务方
- Worker 注册与心跳上报
- 人工重试任务
- 人工终止任务
- 查看死信与补偿记录

## 3. 用户故事
- 作为业务系统，我希望提交异步任务后立即获得 `taskId`，以便后续查询。
- 作为业务系统，我希望任务完成后平台可靠通知我，而不是要求我主动轮询。
- 作为运维人员，我希望能看到任务状态流转和失败原因，以便快速排障。
- 作为 Scheduler，我希望知道 Worker 当前可用并发与资源水位，以便选择合适节点。
- 作为平台管理员，我希望对死信任务进行人工补偿与重试。
