# 需求调研纪要

## 1. 调研目标
梳理集团级异步任务处理场景、现状问题、关键需求和实施优先级。

## 2. 调研结论摘要
- 各业务系统存在大量异步任务场景，但处理方式分散。
- 任务状态不可观测、异常恢复弱是当前最大痛点。
- 业务方更关注接入简单、回调可靠、排障方便。
- 平台方更关注削峰缓冲、可靠调度、Worker 状态感知和运维能力。

## 3. 典型任务类型
- 数据导出
- 对账与结算
- 转码处理
- AI 推理
- 自动化流程执行
- 通知投递

## 4. 核心需求
- 统一任务提交协议
- 任务全生命周期可追踪
- 支持重试、死信、超时兜底
- 业务方回调必达或可补偿
- 调度器能够识别 Worker 资源状态

## 5. 待确认事项
- 业务回调协议是 HTTP 还是 gRPC 为主
- 首批接入业务名单
- TiDB 是否纳入本期
- 各业务方可接受的最大回调重试时长
