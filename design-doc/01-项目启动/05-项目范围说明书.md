# 项目范围说明书

## 1. 项目范围定义
本项目聚焦建设“集团级通用异步任务调度中台”的基础能力，统一承接任务接入、调度、执行、回调与补偿。

## 2. 本期范围
- 统一任务接入 API
- 任务唯一标识生成与幂等控制
- RocketMQ 缓冲排队能力
- MySQL/TiDB 状态持久化
- Scheduler 调度与路由能力
- Worker SDK 与 Worker 状态感知
- 任务终态回调与业务通知
- 重试、死信、超时扫描、补偿
- 监控、告警、运维查询与人工操作

## 3. 范围外内容
- 工作流编排与 DAG
- 精细化租户分级治理
- 复杂任务编排 DSL
- 跨地域容灾多活
- 商业化计费能力

## 4. 边界说明
- 平台负责调度与任务基础设施，不负责业务处理逻辑。
- 平台负责任务生命周期管理，不负责业务数据建模。
- Worker 由业务或平台提供，但执行逻辑属于业务域。

## 5. 验收边界
- 完成首批业务接入
- 完成核心异常场景测试
- 完成压测与监控配置
- 完成灰度与回滚方案验证
