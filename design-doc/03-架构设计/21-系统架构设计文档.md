# 系统架构设计文档

## 1. 文档定位
本文件作为集团级异步任务调度中台的概要架构总纲，详细设计基线请同时参考 [系统架构方案.md](file:///d:/work/project/java-study/rocketmq/ast-platform/系统架构方案.md)。

## 2. 系统分层
- 接入层：Gateway
- 一级缓冲层：RocketMQ
- 存储层：MySQL/TiDB
- 二级调度层：Pump、Dispatcher、Redis
- 执行层：Worker SDK / Worker Group
- 通知与运营层：Callback Service、Notify Dispatcher、Admin

## 3. 核心边界
- 平台负责接入、调度、状态、回调、补偿。
- Worker 负责具体业务执行。
- 业务方负责消费最终通知与接入平台协议。

## 4. 核心链路
- 任务提交链路
- Pump 搬运链路
- Dispatcher 派发链路
- Worker 回调平台链路
- 平台通知业务方链路
- 超时与补偿链路

## 5. 设计原则
- 解耦优先
- 高可用优先
- 最终一致性优先
- 背压感知优先
- 可观测优先
